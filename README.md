# scorlyapp.com

The two pages Scorly owes the outside world: a homepage, and the privacy policy that Google's
OAuth consent screen, Play's data-safety declaration, and `SPEC-DIAGNOSTICS-001`'s consent
wording all link to.

Static HTML, no build step, no dependencies, nothing loaded from another host. Served by GitHub
Pages from `main` at the repository root, with `CNAME` pointing it at the apex domain.

| | |
|---|---|
| `index.html` | What Scorly is, and where to write about it |
| `privacy.html` | What leaves the device, what never does, and the complete diagnostics event list |
| `style.css` | Colour roles copied from `scorly-spec/design/tokens.md` (greyed-brown seed over cool neutrals, `ADR-012`) |
| `sample-scores.html` | Fifteen public-domain scores for testers to import, and where they came from. `noindex`, and not linked from the homepage — the link is handed out with the test invitation |
| `scorly-sample-scores.zip` | The pack itself, 2.4 MB. Twelve Mutopia PDFs and three JPEG renders of a Mutopia page, all **Public Domain**, each page saying so in its own footer |

## The policy is generated by hand from the spec, and must not drift from it

Every factual claim in `privacy.html` is owed to a document in `scorly-spec`:

- the event table is `features/diagnostics-help-improve-scorly.md` under *What is sent*, in plain
  words rather than property names — **it is complete, and adding an event to the app means
  changing this page in the same sitting**;
- *what is never sent* is that spec's own list, including the refusal of IP-derived location;
- *what every event also carries* is that spec's *What the platform attaches* — the nine device
  and build facts the analytics library adds to every event, **and the fact that everything else
  it offers is dropped**. Added 2026-08-28, when a real payload showed nineteen such properties
  arriving where this page implied there were none outside the crash row. Nothing to check it: the
  vocabulary script compares event names, and a property list has no equivalent;
- the consent rules — off by default, revocable, deletion on withdrawal, never a condition of
  using anything — are `adr/ADR-006-diagnostics-leave-by-consent.md`;
- the Drive claims are `features/backup-automatic.md`: the `drive.file` scope, the visible folder
  and its name, the device and installation identifiers, and what signing out does.

A claim here that the app does not keep is worse than no page at all: this is the document the
user reads at the moment they are deciding whether to believe the consent screen.

**One of those obligations is enforced rather than trusted.** The Android repository's
`scripts/check-published-vocabulary.py` compares the event names on this page against the ones the
app can actually send, and its CI runs it against the **live** page on every push to `main` — so
publishing an event without editing this page turns that build red, and so does naming an event
here that the app does not send. Edit `privacy.html` before the app's change lands, not after: the
check is on their side, and the failure it reports is about this page.

Everything else in the list above is still prose against prose, and is only as good as the person
changing it.

## The sample scores are public domain, and that was checked rather than assumed

`scorly-sample-scores.zip` is redistribution, so the licence is the whole question. Mutopia's
catalogue is **mixed** — a piece there can be Public Domain, CC BY, or CC BY-SA, and the search
page states which per piece. Every file in the pack was taken from the Public Domain rows only,
and each rendered page carries the words *Public Domain* in its own footer, which is the check a
stranger can do without trusting this file.

**The engraving is what needed checking, not the music.** A modern edition of a piece whose
composer died centuries ago can carry fresh rights in the typesetting, so a page photographed out
of somebody's own shelf is the risky one to hand around. Mutopia's public-domain engravings are
released outright, which is why they were chosen over anything closer to hand.

If the pack is ever refreshed, re-check the licence column of every piece added — it is per piece,
not per composer, and two engravings of the same work can differ.

This repository is public because GitHub Pages serves from public repositories on the free plan.
It holds nothing that is not already on the internet by intent.
